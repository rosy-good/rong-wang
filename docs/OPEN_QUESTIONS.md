## 2. 处理要求
UI 原型可以先覆盖已冻结核心流程；Q8 操作、Q12 恢复交互和账号维护界面明确标注未决，不伪装成可用功能。认证技术选择不阻碍登录页面的基本原型。
工程设计可提出快照复练选择方式、时间并发排序及显示舍入等实现建议，但必须保持已冻结规则，不能将建议直接称为负责人已确认的新业务。
确认 P1 后同步 PRD、页面、数据库、接口、流程与验收，记录变更。不得借生命周期决策绕过发布锁定、历史保留和既定统计规则。
