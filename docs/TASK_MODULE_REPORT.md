# 任务管理后端验收

日期：2026-11-21。范围：教师任务草稿、选题、发布、复制及学生只读任务接口。依据 [PRD](PRD.md) Q5、Q6 与首次提交前答案保密规则。

## 已实现

- 教师：本课程任务列表、新建草稿、详情、修改任务信息、替换有序草稿题目、发布、复制任务。所有入口检查当前教师与课程归属。
- 学生：已加入课程的已发布任务列表与详情。响应省略标准答案、解析、原始题目 ID，草稿不可见。
- 草稿选题从同课程 `rw_question` 复制完整内容到 `rw_task_question`；可以修改独立草稿副本。发布时校验至少一题、完整题目内容、分值与总分、未来截止时间；发布后任何原任务修改及再次发布均拒绝。复制生成新草稿和独立副本，不复制答卷。
- 数据库沿用现有 `rw_task`、`rw_task_question`；没有新增表或改动开发库。接口字段详见 [API 设计](API_DESIGN.md)。

## 实际验证

本机 Java 17、MySQL 8.0.43，使用新建的隔离 `rongwang_test`（127.0.0.1:13362）执行现有 001、002 建表脚本。通过 MockMvc 调用真实 Controller、Service、MyBatis、事务和数据库。运行 `mvn test`：**66 项通过，失败 0、错误 0、跳过 0**；其中任务模块 6 项。

|---|---|

| 发布后修改题目、名称及再次发布均拒绝 | PASS |
| 复制任务后修改并发布新副本，原任务及答卷不变 | PASS |
