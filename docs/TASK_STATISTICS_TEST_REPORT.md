\## 3. 模块功能范围



\### 3.1 任务管理



\- 教师创建、查询和编辑任务

\- 从题库选择任务题目

\- 任务发布及发布后的修改限制

\- 已有任务复制

\- 学生查看已发布任务

\- 任务访问权限控制



\### 3.2 成绩统计



\- 课程学生人数统计

\- 已提交学生人数及提交率统计

\- 学生最高成绩及代表性提交记录

\- 平均分与整体正确率统计

\- 单道题目正确率统计

\- 学生成绩明细及分页查询



\## 4. 测试工作
