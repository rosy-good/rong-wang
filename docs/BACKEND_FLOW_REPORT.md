# 后端教学闭环验收

日期：2026-11-21。范围：正式提交、自动判分、错题复练、教师统计及已有认证、课程、题库、任务模块回归。业务基线见 [PRD](PRD.md)。

## 已实现

- 学生：截止前提交或重交，保存独立答卷和逐题记录；查看本人历史和提交结果。漏答记录为零分并归集错题；多选使用任务快照答案集合完全匹配。成功提交后返回本次标准答案和解析。
- 幂等与截止：服务器入口记录首次收到本次请求的时间；先校验当前身份及任务成员资格，再查成功幂等记录，未命中才校验严格早于截止时间。同键同内容重试返回原结果；相同键不同正文或任务拒绝。对同一学生先锁账号行再进行数据库一致性读，并发相同键只产生一份答卷。
- 错题：同一学生/原题一条主记录；正式答错或漏答加次数并恢复未掌握，正式答对不变。复练使用最近错误快照；答错加次数、答对自动掌握；手动掌握或取消均保留历史。复练也执行幂等校验。
- 教师：查看任务提交历史、逐份答卷、当前成员提交状态；按最高分、并列取最后一次最高分答卷计算提交率、平均分、班级及逐题正确率。
- 题库原题与任务快照继续分表保存。现有 10 张物理表足够，无需迁移开发数据库。接口字段和状态码见 [API 设计](API_DESIGN.md)。

## 实际验证

本机 Java 17 与 MySQL 8.0.43；使用隔离实例 127.0.0.1:13362 和可丢弃的 `rongwang_test`，导入项目 001、002 建表脚本。MockMvc 调用实际后端业务、事务和 MySQL；**没有浏览器或真实网络 Cookie 联调**。测试环境变量及复现方法见 [后端 README](../backend/README.md)。

最终执行后端 `mvn test`：**74 项通过，失败 0、错误 0、跳过 0**；其中本次提交、错题和统计集成测试 8 项。测试库中保留随机生成的测试数据，未改动 3306 开发库。

| 同键重试、不同正文冲突、并发同键只存一份答卷 | PASS |
| 截止前接收、恰好截止拒绝、截止后成功重试 | PASS |
| 多选顺序无关、漏选零分、非法选项整次拒绝 | PASS |
| 漏答逐题零分、错题创建及错误次数去重 | PASS |

测试过程中发现并修复两个问题：首次答卷结果读取时 MySQL 时间列被当作另一种 Java 类型；并发同键提交在旧事务视图下可能撞唯一约束。修正日期映射与学生行加锁顺序后，全量回归通过。截止边界测试使用数据库实际保存的毫秒值，避免将纳秒值误判为“恰好截止”。
