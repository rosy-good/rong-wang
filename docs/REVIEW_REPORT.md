审查日期：2026-11-11。对象：AGENTS.md、八份原需求文档及本报告，共十份 Markdown。依据：产品负责人本轮正式确认的业务规则。结论适用范围为需求文档基线与第二阶段 UI 原型准备，不是软件测试或上线验收。

## 1. 第一阶段总结
融网学习平台的教师发布任务、学生作答、后端自动判分、错题归集、复练及掌握状态闭环已完成需求整理。采用既定 Vue 3 / TypeScript 前端、Java / Spring Boot 后端、MySQL 与 REST 单体架构，不增加复杂基础设施或业务范围。
本次重新组织旧的累计补丁，统一术语、页面职责、数据库字段、API 与验收。只修改 Markdown，没有业务代码、工程初始化或依赖安装。

## 2. 全部已确认业务规则
以下均已冻结，完整规则与示例见 [PRD](PRD.md)。

| 规则 | 已确认内容 |
|---|---|
| Q1 | 教师学生均由维护者预创建；固定单角色；无自助注册；支持启用禁用，禁用不能登录；密码安全哈希。2026-11-14 补充确认 Session 与初始化 SQL，第一版无管理员界面 |
| Q2 | 截止前不限次提交，每次成功保存独立答卷；最终成绩取历史最高分；并列取最后一次最高分答卷统计；低分不降低成绩；同幂等请求不重复建答卷 |
| Q3 | 首次成功前不泄露答案解析；成功后立即公开本次答案解析；重交正常判分、保留历史；重开页面不能令答案重新保密 |
| Q4 | 以服务器首次收到新请求时间为准，严格早于截止；等于或晚于均拒绝，提前点击但晚到同样拒绝；已成功同键重试截止后返回原结果；客户端时间无效 |
| Q5 题库 | 每课程独立题库；教师仅管理自己课程；不同课程不能直接共用原题；任务只能从本课程选题 |
| Q5 邀请码 | 有效码直接加入无审批；教师可重置，旧码立即失效；默认不自动过期；课程归档后失效；原成员不受重置影响；重复加入不重复建成员 |
| Q6 | 草稿可改，发布后完全锁定，不得改题、选项、答案、分值、解析、顺序、任务信息或截止，不得撤回；纠错复制新任务修改再发布；独立完整快照保留 |
| Q7 漏答 | 允许漏答，零分，保存逐题记录并归集错题；非法选项拒绝整次提交，不作普通答错 |
| Q7 分值 | 大于零，最多两位小数；MySQL DECIMAL(8,2)，Java BigDecimal |
| Q7 多选 | 至少两项正确答案，集合完全相等得满分；少选多选错选零分；顺序无关；重复或未知选项拒绝；后端按任务快照判分 |
| Q9 | 学生与原题唯一错题；首次正式错误为 1 未掌握；正式再次错误加 1 恢复未掌握；正式正确不改变状态；复练错误加 1 恢复未掌握，复练正确自动掌握；可手动标记和取消；全部历史保留；同键不重复加次数 |
| Q10 | 提交率用已提交学生/当前成员，后来加入者计分母；平均分取每人最高分后平均；每人最高分代表答卷，并列选最后一次；正确率为代表正确题数/(已提交人数×任务题数)；未提交不参与平均分和正确率；漏答算错误并计分母；复练排除；重交不重复计人数 |
| Q13 | 有效邀请码直接加入无审批，后端验证邀请码、课程状态及当前身份；重复加入返回已有关系 |

## 4. 数据库一致性检查
十张表可表达账号、课程多成员、课程多任务、任务多题、多次正式答卷、逐题答案、个人错题和复练历史。
question 与 task_question 分表，后者具备完整题目内容与 position；submission_answer 关联快照。mistake 按 student_id + question_id 唯一；正式答卷没有 task_id + student_id 唯一限制。
received_at 用于截止，submitted_at 保存成功时间，attempt_no 工程排序方案用于同分最后答卷；不混淆三种含义。bestScore 与代表 ID 由成功答卷计算，不设置会被低分覆盖的最终分字段。
DECIMAL(8,2) 和 BigDecimal 对齐，明确单题校验和总分溢出校验。错题更新、答卷写入同事务，复练同样保持事务一致。Q8 生命周期字段和入口未擅自定案。

## 6. 页面与流程一致性检查
教师从课程题库选题，草稿发布后只读；错误使用复制入口创建新任务，接口和数据库都新增独立记录。
学生有效码直接入课，无审批页；截止前不限次作答，首次成功后立即公开答案；超时复用原键，客户端倒计时不替代服务器判断。
错题页面有标记/取消掌握，复练正确自动掌握，正式正确不触发。教师统计有平均分及代表答卷标识。下一阶段为 UI 原型，不误跳过原型进入工程初始化。

## 7. 发现冲突及修复
| 原冲突或缺漏 | 修复 |

| 原发布过程可能以最新题库覆盖复制后修改的内容 | 发布最终确认草稿快照，不覆盖教师已修改的独立副本 |
