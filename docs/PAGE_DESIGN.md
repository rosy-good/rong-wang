# 页面设计基线

基线日期：2026-11-11。此文档定义第二阶段 UI 原型的页面范围；已制作本地 V1 供评审，尚未完成浏览器视觉验证。路由为设计建议。

阶段进度：负责人已授权启动第二阶段，现已制作 [可点击原型 V1](../prototype/index.html)，范围、演示路径和验证限制见 [UI_PROTOTYPE.md](UI_PROTOTYPE.md)。下方路由仍是未来正式产品的路由建议，本地原型通过视图切换呈现，不表示路由已经开发完成。

## 1. 公共页面
| 路由 | 功能 |
|---|---|
| /login | 预创建账号密码登录、错误提示；禁用不能登录，无注册入口 |
| /403、/404 | 无权访问或资源不存在，返回可访问页面 |

第一版使用 Session；账号由维护者通过初始化 SQL 管理，不新增管理后台页面。

题库前端对接约定（2026-11-21）：选项使用 key/text，判断题固定 A「正确」、B「错误」；分值以字符串传输。保存失败展示后端校验信息并保留表单。编辑原题不转移课程、不更改任务快照。字段长度和 PATCH 语义见 [API 设计](API_DESIGN.md)；本次仅后端实现，页面尚未接入真实接口。

## 2. 教师页面
正式前端入口补充（2026-11-22）：侧栏新增“成绩统计” `/teacher/statistics`，先选择课程；课程详情新增“成绩统计”快捷卡片，进入 `/teacher/courses/:id/results` 选择任务。已发布任务跳转到原有 `/teacher/tasks/:id/results` 展示统计，草稿显示“尚未发布，暂无成绩”。入口复用原有接口和 Q10 统计口径。

| 路由 | 功能 |
|---|---|
| /teacher/courses | 本人课程列表、创建入口 |
| /teacher/courses/new | 新建课程名称与介绍 |
| /teacher/courses/:id/edit | 编辑课程名称与介绍；无已定案归档/删除操作 |
| /teacher/courses/:id | 概览、邀请码展示与重置确认，提示旧码立即失效、原成员保留 |
| /teacher/courses/:id/students | 当前成员、加入时间；无审批 |
| /teacher/courses/:id/questions | 独立题库按题干关键词、题型检索及分页，新增、编辑入口 |
| /teacher/courses/:id/questions/new | 三种题型、题干选项、答案解析、正数最多两位小数分值 |
| /teacher/questions/:id/edit | 编辑原题，提示不会改变已发布任务 |
| /teacher/courses/:id/tasks | 草稿、已发布、已截止任务列表 |
| /teacher/courses/:id/tasks/new | 同课程选题、排序、名称说明及截止时间 |
| /teacher/tasks/:id/edit | 仅编辑草稿，含复制来的题目副本；预览确认后发布 |
| /teacher/tasks/:id | 已发布只读快照；复制为新任务入口，无修改截止或撤回按钮 |
| /teacher/tasks/:id/results | 已提交/未提交名单、每人最高分、代表答卷标识、历次答卷；提交率、班级平均分、整体及逐题正确率 |
| /teacher/submissions/:id | 指定尝试的逐题答案、分数、快照解析及时间 |

复制操作生成同课程新草稿并进入编辑页，原任务保持锁定。草稿发布提醒“发布后不能修改或撤回，错误需复制新任务”；后端必须同样拒绝绕过。

## 3. 学生页面
| 路由 | 功能 |
|---|---|
| /student/courses | 已加入课程；邀请码加入弹窗，有效码直接加入，重复加入提示已有关系 |
| /student/courses/:id | 基本信息、已发布任务和本人提交状态 |
| /student/tasks/:id | 说明、截止、总分、最高分、历次提交入口；截止前不限次重交 |
| /student/tasks/:id/answer | 作答、导航、漏答提示和确认提交；允许带漏答提交，不含标准答案解析 |
| /student/submissions | 全部提交历史，按课程任务筛选 |
| /student/submissions/:id | 本次成绩、当前最高分、统计代表标识；成功后立即展示本次答案解析 |
| /student/mistakes | 按课程和掌握状态筛选，显示错误次数和最近错误时间 |
| /student/mistakes/:id | 错题及历史、复练入口、标记掌握与取消掌握 |
| /student/mistakes/:id/practice | 按快照复练，结果说明答对已掌握、答错恢复未掌握且次数加一 |

正式答对不改变掌握状态，结果页不能提示“正式答对自动掌握”。首次成功前答案不得进入响应或隐藏页面数据；重回作答页隐藏答案只是交互，不能宣称答案重新保密。

## 4. 交互与异常
列表提供加载、空数据、失败、分页状态。按钮提交中禁用且复用同一幂等键；超时先重试原请求或查历史，不立即创建新尝试。客户端倒计时仅提示，服务器收到新请求等于/超过截止时拒绝；成功原请求可在截止后重试查看。
统计未提交成绩显示“未提交”，有零分提交显示 0；无平均分或正确率数据时显示“暂无数据”。一人多次提交只计一次人数，最高分并列标记最后取得最高分的答卷。
Q8 生命周期、Q12 自动保存恢复交互为未决占位，不作为可用按钮；Q11 部署容量由后续明确。页面退出提示可在原型讨论，不能承诺已实现自动保存。
