# 功能清单与模块划分

基线：2026-11-11；业务规则以 [PRD](PRD.md) 为准。

## 1. 教师端
| 模块 | 功能 |
|---|---|
| 登录 | 使用维护者预创建账号登录、退出；禁用账号不能登录 |
| 课程 | 创建、编辑、查看自己的课程；查看和重置邀请码，旧码立即失效 |
| 成员 | 分页查看课程学生及加入时间，不设加入审批 |
| 题库 | 本课程单选、多选、判断题查询、新增、编辑；维护答案、解析及正数两位小数分值 |
| 任务 | 从同课程题库选题、排序，设置名称、说明、截止时间，编辑草稿并发布 |
| 已发布任务 | 只读查看独立快照；复制为新草稿纠错，不提供延期、撤回或原地编辑 |
| 提交 | 查看已提交、未提交名单和每次独立答卷 |
| 统计 | 展示学生最高分及代表答卷、提交率、班级平均分、整体和逐题正确率 |

## 2. 学生端
| 模块 | 功能 |
|---|---|
| 登录 | 预创建单角色账号登录，无自助注册 |
| 课程 | 输入有效邀请码直接加入；重复加入返回已有关系；查看已加入课程 |
| 作答 | 查看已发布任务，允许漏答；服务器收到请求早于截止时不限次提交 |
| 结果 | 成功后立即查看本次答案、解析、逐题分数；查看最高分及完整提交历史 |
| 错题 | 按课程、掌握状态筛选；查看次数、最近错误时间及历史 |
| 复练与掌握 | 复练答对自动掌握、答错加次数并恢复未掌握；支持手动标记及取消掌握 |

正式答对不改变错题掌握状态；正式答错或漏答自动归集。同键重试不重复建答卷、不重复增加错误次数。低分重交不降低最高分，并列最高分使用最后一次取得最高分的答卷统计。

## 3. 平台维护与范围
维护者通过初始化 SQL 预创建、启用或禁用账号，密码使用 BCrypt 安全哈希保存。第一版使用 Session，不增加管理员 Web 模块。
课程/成员/题目/任务的删除、退出和归档操作待 Q8；自动保存与恢复待 Q12；部署与容量待 Q11。自助注册不开放；视频、支付、主观题、审批、消息系统均不纳入本版。

## 4. 前端模块
- auth：登录、退出、本人身份；Vue Router 路由守卫和 Pinia 用户状态。
- courses：课程、邀请码加入和重置、成员列表。
- questions：题库及题目编辑器。
- tasks：草稿、选题、发布、复制新任务及在线答题。
- submissions：历次结果、最高分、代表答卷及教师统计。
- mistakes：错题筛选、复练、掌握和取消掌握。
- shared：Element Plus 通用组件、Axios、分页和错误提示。

前端守卫不能替代后端鉴权；作答响应不携带答案解析，已成功提交的本人结果接口公开答案。

## 5. 后端模块
认证、课程、题库、任务、答卷判分、错题、统计按业务分层；Controller 接收请求、Service 执行业务、Mapper 访问 MySQL，不拆微服务。
服务器先记录可信接收时间；验证身份权限后识别成功幂等请求，再对新请求校验截止。正式提交与错题更新统一事务；发布复制快照并锁定任务；所有修改入口执行发布状态检查。BigDecimal 计算分数，数据库用 DECIMAL(8,2)。
统计统一使用每人最高分及并列时最后一份最高分答卷，不能直接把全部提交相加。
